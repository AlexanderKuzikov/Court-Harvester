# Court-Harvester — DECISIONS

<!-- Append-only. Формат фиксирован. -->

## 2026-02-18: API-first, только DaData

**Контекст:** Нужен полный справочник судов РФ.

**Решение:** Использовать только DaData suggestions API, без HTML-скрапинга.

**Альтернативы:** sudrf.ru scraping (CourtSudrf), kad.arbitr.ru.

**Trade-off:** Нет телефонов/email/ПСП, но стабильный API и 10206 записей.

## 2026-02-18: Умный брутфорс префиксов

**Контекст:** DaData не даёт полный список, только suggest по запросу.

**Решение:** Многоуровневое расширение: 1 буква → 2 буквы → 3 буквы.

**Альтернативы:** Перебор всех 100×14×10000 кодов (14M запросов).

**Trade-off:** ~19K запросов вместо 14M, но требует эвристики остановки.
